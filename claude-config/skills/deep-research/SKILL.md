# Deep Research Skill

## Research Protocol

### Phase 1: Scope Definition
Before researching, clarify:
1. The specific research question (not just a topic)
2. Required depth (overview vs. expert-level)
3. Time scope (historical, current, future-looking)
4. Source preferences (academic, industry, news, primary sources)
5. Deliverable format (report, summary, bullet list, annotated bibliography)

### Phase 2: Source Strategy
Use a multi-source approach:
- Primary sources: official documentation, original research papers, direct data
- Secondary sources: analysis articles, expert commentary, reviews
- Triangulate: a claim is reliable when 3+ independent sources agree
- Note source recency - prefer sources from the last 2 years for fast-moving topics

### Phase 3: Structured Information Gathering
For each source:
1. Record the claim or finding
2. Note the source (title, author, publication, date, URL)
3. Assess credibility (peer-reviewed, industry authority, unknown)
4. Note any conflicts with other sources

### Phase 4: Synthesis
- Group related findings by theme, not by source
- Highlight consensus views vs. contested areas
- Explicitly note what is NOT known or where evidence is thin
- Surface surprising or counterintuitive findings

## Citation Standards

Use inline citations in the format: [Author, Year] or [Source Name, Date]
At the end of the report, list all references:
```
[1] Author Name, "Title," Publication, Date, URL
```

Never fabricate citations. If a source cannot be verified, label it as "unverified" or exclude it.

## Research Report Structure

```
# [Research Question]

## Executive Summary (3-5 sentences)

## Key Findings
- Finding 1 [source]
- Finding 2 [source]

## Detailed Analysis
### Theme 1
### Theme 2

## Conflicting Evidence / Open Questions

## Methodology Note

## References
```

## Quality Checks

Before delivering research output:
- [ ] Every factual claim has a source
- [ ] Conflicting evidence is acknowledged
- [ ] Limitations of the research are stated
- [ ] Conclusions are proportionate to the evidence
- [ ] No hallucinated citations (verify each one is real)
